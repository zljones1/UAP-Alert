# UAP Alert

Browser retro FPS (VOIDSTATION engine). Wolfenstein-style raycaster. Sector Helix-9 space station overrun by biomass.

Built with Grok. Single file — open `index.html` in Chrome or Edge.

## Play

1. Open `index.html` in Chrome or Edge
2. Click **DEPLOY**
3. Click the game once so mouse-look locks

After GitHub Pages is on: https://zljones1.github.io/UAP-Alert/

## Controls

- WASD / arrows: Move
- Mouse: Look
- Click or Space: Fire
- Shift: Sprint
- Q / E: Turn
- F: Fullscreen
- Phone: left stick + FIRE

## Objective

Clear every crawler and stalker. Cyan packs = ammo. Red packs = medfoam. Reach CORE.
