# UAP Alert

Doom-architecture browser FPS. Aliens on Sector Helix-9.
Original maps, art, and synthesized sounds — not id source, not Doom 2 WADs.

## Play
Open `index.html` (needs `engine.js` in the same folder).

Pages (after enabled): https://zljones1.github.io/UAP-Alert/

## Controls
WASD move, mouse look, click fire, 1 shotgun / 2 plasma, shift run, F fullscreen.

## Engine
320x200 software renderer, 35 Hz tic, column walls, perspective flats, billboard sprites, Web Audio SFX.
